## 10주차 모바일 메뉴 및 메모 필터 기능 추가

### 확인할 문제

모바일 화면에서 메뉴가 차지하는 공간을 줄이고, 저장한 메모를 상태별로 구분할 필요가 있었다. 또한 목록을 다시 표시할 때 이전 요소가 남거나 목록 표시 조건이 반대로 설정되는 문제가 있었다.

### 수정한 내용

- 메뉴 토글 버튼과 `is-open` 클래스를 이용해 모바일 메뉴를 열고 닫도록 했다.
- 메뉴 버튼의 `aria-expanded` 값을 열림 상태와 연결했다.
- 메뉴 항목 선택 시 메뉴가 닫히도록 클릭 이벤트를 추가했다.
- URL의 해시값을 이용해 현재 선택한 메뉴에 `aria-current`를 적용했다.
- 메모 목록에 전체, 저장됨, 취소됨 필터 버튼을 추가했다.
- `data-filter`와 배열의 `filter()`를 사용해 선택된 조건에 맞는 메모를 구분하도록 했다.
- 필터 선택 시 `is-active`, `aria-pressed` 상태를 갱신하도록 했다.
- `renderPlans()`에서 `replaceChildren()`으로 이전 목록을 지우고 다시 생성하도록 했다.
- 목록과 빈 상태 영역의 `hidden` 조건을 수정했다.
- 필터 버튼을 누르면 `readPlans()` 대신 `renderPlans()`를 호출하도록 했다.

### 확인할 기능

모바일 메뉴 토글 / 메뉴 선택 표시 / `aria-expanded` / `aria-current` / `hashchange` / 메모 필터 / `data-filter` / `filter()` / `replaceChildren()` / 빈 목록 안내

### 확인할 화면 너비

## 11주차 웹 접근성 개선

### 확인할 문제

마우스로는 조작할 수 있어도 키보드 사용자에게 현재 메뉴와 필터 상태가 명확히 전달되지 않았고, 본문 이동, 입력 오류, 저장 상태, 필터 결과 안내에도 개선이 필요했다.

### 수정한 내용

- 페이지 처음에 본문 바로가기 링크를 추가하고, 키보드 초점이 있을 때 나타나도록 CSS를 적용했다.
- 본문 영역에 `tabindex="-1"`을 적용해 바로가기 링크로 접근할 수 있도록 했다.
- 현재 메뉴의 `aria-current="page"`와 선택된 필터의 `aria-pressed="true"`에 굵기와 밑줄 스타일을 적용했다.
- MindStore 소개 이미지의 대체 텍스트를 점검하고, 화면 요소의 이름을 이해할 수 있도록 수정했다.
- `updateCurrentNav()`에서 현재 메뉴명을 읽어 브라우저 탭 제목을 `메뉴명 | MindStore` 형태로 변경하도록 했다.
- 메모 수정 대화상자에 닫기 버튼을 추가하고 의미를 알 수 있는 이름을 설정했다.
- 메모 제목의 글자 수 표시를 별도 요소로 분리하고, 오류 안내에 `aria-invalid`를 연결했다.
- 중요도 설정 체크박스를 해제하면 선택 영역을 숨기고 라디오 버튼도 `disabled` 처리하도록 했다.
- 저장 중에는 `aria-busy`와 버튼 비활성화, 상태 메시지를 사용하고 저장 성공과 실패를 구분해 안내하도록 했다.
- 모바일 메뉴가 열렸을 때 `Escape` 키로 닫고, 메뉴 버튼으로 키보드 초점을 돌려주도록 했다.
- 필터별 메모 개수와 결과가 없는 상태를 안내하고, 결과가 없을 때 `전체 보기`로 돌아갈 수 있도록 했다.
- 메모 취소 및 취소 되돌리기 기능을 필터와 연결하고, 상태 변경 후 카드 버튼이나 선택한 필터에 초점이 남도록 처리했다.
- 기존 수정, 삭제, 메모 목록, 로컬 저장 기능을 유지했다.

### 확인할 기능

본문 바로가기 / 키보드 Tab·Enter·Escape / 초점 표시와 복귀 / 이미지 대체 텍스트 / `aria-current` / `aria-pressed` / `aria-expanded` / `aria-invalid` / `aria-busy` / 글자 수 안내 / 조건부 입력 `hidden`·`disabled` / 저장 상태 / 메모 취소·복구 / 필터 결과 및 빈 목록 안내

### 확인할 화면 너비

데스크톱 / 600px 이하 모바일 / 390px
