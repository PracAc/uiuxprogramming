## 4주차 반응형 수정

### 확인할 문제
작은 화면에서 메뉴, 기능 카드, 이메일 폼이 좁여 보였다.

### 수정한 내용
- viewport 메타 태그를 추가했다.
- 콘텐츠에 width와 max-width를 함께 사용했다.
- 기능 카드 목록을 반응형 Grid로 변경했다.
- 768px 이하에서 메뉴, 카드 폼을 한 열로 구성했다.

### 확인할 화면 너비

1100px / 769px / 768px / 390px


## 5주차 JavaScript 이벤트 처리

### 확인할 문제

HTML과 CSS만으로는 버튼 클릭이나 사용자 입력에 따라 화면을 변경할 수 없었다.

### 수정한 내용
- JavaScript 파일을 연결했다.
- 이메일 입력값을 가져와 서비스 신청 기능을 구현했다.
- submit 이벤트에서 기본 동작을 막기 위해 preventDefault를 사용했다.
- 이메일을 입력하지 않은 경우 안내 문구를 표시하도록 처리했다.
- 신청 완료 후 버튼과 안내 문구의 상태를 변경했다.

### 확인할 기능

이메일 입력 / 서비스 신청 / 신청 완료 메시지 / 버튼 비활성화

## 6주차 동적 UI 기능 추가

### 확인할 문제

사용자의 선택이나 입력에 따라 화면이 바로 변경되는 기능이 필요했다.

### 수정한 내용
- 버튼 클릭으로 라이트 테마와 다크 테마를 변경하도록 했다.
- 이용자 이름 입력 시 현재 글자 수를 표시하도록 했다.
- 체크박스 동의 여부에 따라 서비스 이용 버튼을 활성화했다.
- 메모 기능을 탭으로 구성하고 선택한 내용만 표시하도록 했다.
- data-target과 hidden 속성을 이용해 탭 화면을 전환했다.

### 확인할 기능

테마 변경 / 이름 글자 수 / 이용 동의 / 버튼 활성화 / 탭 전환


## 7주차 단계별 메모 작성 기능 구현

### 확인할 문제

메모 작성 시 제목, 기한, 중요도 등의 정보를 한 화면에서 입력하면 사용자가 작성 과정을 확인하기 어려웠다.

### 수정한 내용

- 서비스 이용 전 녹음 활용 안내창을 추가했다.
- 메모 작성 과정을 정보 입력, 조건 선택, 내용 확인 단계로 나누었다.
- 메모 제목을 입력하지 않은 경우 오류 메시지를 표시하도록 처리했다.
- range를 이용하여 메모 기한을 선택할 수 있도록 했다.
- 체크박스와 라디오 버튼을 이용하여 메모 중요도를 설정하도록 했다.
- 입력한 제목, 기한, 중요도를 작성 완료 전에 확인할 수 있도록 했다.
- 이전 버튼을 통해 앞 단계로 이동할 수 있도록 했다.
- 작성 완료 후 다시 설정하기 기능을 추가했다.

### 확인할 기능

녹음 활용 안내 / 메모 제목 입력 / 입력값 확인 / 메모 기한 설정 / 중요도 설정 / 단계 이동 / 작성 내용 확인 / 다시 설정하기

## 중간고사 메모 목록 관리 기능 구현

### 확인할 문제
기존에는 메모 작성 완료 후 입력한 내용을 확인할 수 있었지만, 작성한 메모를 목록으로 관리하거나 수정 및 삭제할 수 없었다.

### 수정한 내용
- 메모 작성 완료 시 입력한 제목, 기한, 중요도를 메모 목록에 추가하도록 했다.
- localStorage를 이용하여 새로고침 후에도 작성한 메모가 유지되도록 했다.
- 메모 목록을 테이블 형태로 구성하고 제목, 기한, 중요도를 표시하도록 했다.
- 각 메모에 수정 및 삭제 버튼을 추가했다.
- 수정 버튼 클릭 시 기존 메모 정보를 불러와 변경할 수 있도록 했다.
- 메모 수정 시 제목을 입력하지 않으면 오류 메시지를 표시하도록 했다.
- 삭제 버튼 클릭 시 확인창을 표시하고 취소하면 기존 메모가 유지되도록 했다.
- 등록된 메모가 없는 경우 안내 문구를 표시하도록 했다.
- 기존 다크모드 기능을 메모 목록과 수정 화면에도 적용했다.
- 768px 이하에서는 메모 목록을 세로 형태로 배치하도록 반응형 CSS를 추가했다.

### 확인할 기능

메모 목록 추가 / 메모 목록 조회 / 메모 수정 / 입력값 검증 / 수정 취소 / 메모 삭제 / 삭제 취소 / 빈 목록 안내 / localStorage 저장 / 다크모드 전환 / 모바일 반응형

- 확인할 화면 너비
1100px / 769px / 768px / 390px
